Build Scraper

Pull a build out of any Minecraft Java world, 1.12.2 to the latest release, and save it as a .schem, .litematic or structure .nbt for WorldEdit, FAWE, Litematica or a structure block. Look at any build in 3D first.

Problems

    Open a world save

    Or drag the world folder or .zip here. Nothing is uploaded; the world is read inside your browser.
    • Windows: %appdata%\.minecraft\saves
    • macOS: ~/Library/Application Support/minecraft/saves
    • Linux: ~/.minecraft/saves
    Servers: use the world folder from the server (for example world, with world_nether as its own folder on Spigot/Paper).
    Drag on the map to draw a box around your build. Scroll to zoom.

    Format
    Load it in Minecraft
    WorldEdit or FAWE (.schem)
    Put the file in .minecraft/config/worldedit/schematics (singleplayer) or plugins/WorldEdit/schematics (server). In game run //schem load name, stand where the corner should go, then //paste. //paste -a skips air.
    Litematica (.litematic)
    Put the file in .minecraft/schematics. Press M, choose Load Schematics, pick the file and press Load. A see-through hologram appears that you can build from block by block, or paste in creative.
    Structure block (.nbt)
    Put the file in saves/YourWorld/generated/minecraft/structures. Then run /place template minecraft:name (1.19+), or use a structure block in Load mode with the name name. Structure blocks only load up to 48 × 48 × 48.
    MineDojo
    Run python minedojo_view.py name.schem from the download. It builds the schematic in a MineDojo world, saves screenshots and an orbit GIF, then deletes that world.

    Convert schematics

    Works with old MCEdit .schematic files (pre-1.13 block IDs are converted), Litematica .litematic, structure block .nbt, and older .schem versions. You can also drop a .zip full of them.

    Files

    Search for builds

    Type what you're looking for. Search public GitHub projects, or one website you choose. Matching schematic files are listed so you can pick which to convert.

    The site search reads up to the number of pages you set, one page at a time, and only on that site. Put {q} in the address to start from the site's own search page.

    Grab schematics from a web page

    Paste a link to a schematic file, a .zip, or a page that links to schematic files. Matching files are listed so you can pick which to convert.

    Some sites block other pages from reading their files. When that happens, download the file in your browser and use the Convert tab, or run the command-line helper that comes with this tool: node mcbs.mjs fetch URL. Please follow each site's rules and only download builds you're allowed to use.

    My builds

    Minecraft RL Build Generator

    A separate program in the minecraft build gen folder. A reinforcement-learning agent builds houses, watchtowers, step pyramids, gate arches and castle walls block by block from a short prompt such as two 7x9 birch cottages, and exports them as .schem, .schematic or a data pack for Java 1.12.2 to 26.3. It can also learn new build types from your own schematics.

    To use it, double-click start.bat in that folder (needs Node.js 18 or newer). It runs on your computer at http://127.0.0.1:4321 while its window stays open. Full steps are in HOW_TO_USE.txt.

    Builds it has made

    The schematics in minecraft build gen/output/schematics. The same builds are in its data pack, output/rlbuild_datapack, as /function rlbuild:house_1 and so on.

    Runs entirely in your browser. Reads Anvil worlds from 1.12.2 through 26.x, including pre-1.13 numeric block IDs. Block entities from pre-1.13 worlds are upgraded where possible; check redstone and modded blocks after pasting.
