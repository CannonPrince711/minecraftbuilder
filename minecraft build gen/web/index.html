Teach it your own builds

Upload schematics of anything: a windmill, a ship, a statue, a shop. How to use your builds

1. Pick your Minecraft version

Choose it in Settings before downloading. Files are made for exactly that version, from 1.12.2 up to the latest. On older versions, blocks that didn't exist yet (cherry wood, deepslate, mud bricks) are swapped for similar older blocks.

2a. Schematics + WorldEdit (best for servers and big builds)

  1. Install WorldEdit for your version (Forge, Fabric, or as a Bukkit/Paper plugin).
  2. Download the schematics. Unzip them into the WorldEdit schematics folder:
    • Singleplayer (Forge/Fabric): .minecraft/config/worldedit/schematics/
    • Server (Bukkit/Paper/Spigot): plugins/WorldEdit/schematics/
  3. In game: //schem load house_1, then stand where you want it and //paste.
  4. 1.12.2 uses .schematic files with WorldEdit 6: //schematic load house_1, then //paste.

2b. Data pack (no mods needed)

  1. Click Install and pick your world, or download the data pack and unzip it into <world>/datapacks/.
  2. In game: /reload, then /function rlbuild:list to see your builds.
  3. Stand on flat ground and run e.g. /function rlbuild:house_1. It appears 2 blocks toward +X/+Z.
  4. Careful: it first clears an 11×11×11 area to air.
  5. 1.12.2 has no data packs: the zip contains a data/functions folder that goes into the world folder. Install does this for you.

Build Scraper & Schematic Viewer

This program works together with Build Scraper (pulls builds out of your worlds or finds them online) and Schematic Viewer. All three read and write the same files: .schem v2/v3, .schematic, .litematic and structure .nbt, from 1.12.2 to the latest version.

  • Train on builds from your worlds: scrape them with Build Scraper (they save to Downloads), then in Train → “Or use files Build Scraper saved” tick them, give the kind a name and press Use ticked files. Zips of many files work too.
  • Look at a generated build in the Viewer: press Viewer on a card.
  • Pick the file type next to the download buttons: WorldEdit, WorldEdit 7.3+ (v3), Litematica or structure block.
  • Both programs are found automatically next to this one. If not, set their folder in the Control Center under Settings.

Realism sliders

The Realism box adds finishing touches after the AI builds: Weathering (moss, cracks), Block variety (mixing similar blocks), Exterior details (path, lanterns, shutters), Interior (furniture, carpet, light), Nature (grass, flowers, bushes, vines) Ruin (missing blocks, broken windows, cobwebs) and Physics (parts without enough support fall and land as rubble; higher is stricter). Previews update as you drag; downloads and Install use the current values. Words like abandoned, collapsed, mossy, cozy, overgrown or realistic in your prompt set them for you. Older versions get stand-ins (torches instead of lanterns before 1.14).

Writing prompts

The prompt reader understands: structure (house, cottage, tower, castle, pyramid, temple, arch, gate, wall…), theme words (oak/wooden, spruce/dark/nordic, birch/white, desert/sand, cherry/pink/japanese), roofs (flat/modern, gable/pitched, hip/pyramid roof), sizes (small, big, tall, short, wide, narrow, 7x9, 8 tall), counts (3 towers, a few huts) and variety (neat or varied). Everything it picked up shows as chips under the prompt.

MineDojo: real renders + prompt matching (optional)

MineDojo is NVIDIA's open Minecraft research framework. Test in MineDojo places every build inside its real Minecraft, films a 16-frame orbit around it, and lets MineCLIP (a video–text model trained on Minecraft YouTube) score how well each build matches your prompt. Cards then show real in-game screenshots and are sorted best match first.

MineDojo runs on Linux or macOS. On Windows, use WSL2:

  1. In PowerShell (admin): wsl --install, then open Ubuntu.
  2. In Ubuntu: sudo apt update && sudo apt install -y openjdk-8-jdk xvfb python3.9 python3.9-venv
  3. python3.9 -m venv ~/minedojo && source ~/minedojo/bin/activate
  4. pip install minedojo git+https://github.com/MineDojo/MineCLIP
  5. Download the MineCLIP attn checkpoint (link in the MineCLIP README) and save it as minedojo/attn.pth in this folder.
  6. That's it: this app finds ~/minedojo inside WSL by itself. (Installed somewhere else? Put that Python in Control Center → Settings → MineDojo Python, e.g. wsl /home/you/env/bin/python; on Linux/macOS just the path to the Python.)

Teach it something new

      
Easiest: open the Train tab, give the kind of build a name (e.g. “Windmill”), drop in a few .schem, .schematic or .nbt files, then press Train it now. It learns from your examples and uses your blocks. Afterwards prompts like “3 big windmills” pick your new type. Upload more files under the same name at any time, then retrain.

      
By hand (rule-based): copy a file in src/structures/, describe where walls, columns, roofs and openings go in its zone() function, register it in src/structures/index.js, restart this app and train it in the Train tab.
